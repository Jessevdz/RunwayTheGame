import { Aside, Steps, Tabs, TabItem } from '@astrojs/starlight/components';

Runway is open source and self-hosted. You need [Docker with Compose](https://www.docker.com), a box your players'
phones can reach, and a domain name with a TLS certificate.

<Aside type="danger" title="HTTPS is a requirement">
Browsers refuse geolocation and the camera outside a secure context.
</Aside>

<Steps>

1. ### Clone the repository

   ```bash
   git clone https://github.com/Jessevdz/RunwayTheGame.git
   ```

2. ### Write the `.env`

   ```bash
   cp .env.example .env
   ```

   | Variable | What to put in it |
   | :--- | :--- |
   | `RUNWAY_DB_PASSWORD` | Any strong password. Only the containers ever use it |
   | `S3_ACCESS_KEY` | MinIO root username / S3 access key ID |
   | `S3_SECRET_KEY` | The MinIO root password / S3 secret access key |
   | `RUNWAY_WORKER_TOKEN` | Shared secret authenticating the background verification worker when submitting AI photo grading verdicts to the server |
   | `RUNWAY_ROADMAP_ADMIN_KEY` | Secret key for roadmap and admin management|
   | `S3_PUBLIC_ENDPOINT` | Your public URL, e.g. `https://race.example.com`.|
   | `RUNWAY_ALLOWED_ORIGINS` | Comma-separated browser origins for the API and WebSocket (e.g. `https://race.example.com`). Leave empty locally for loopback/LAN origins |
   | `SCALEWAY_API_KEY` | Optional: Scaleway API key to enable AI photo grading (or `GEMINI_API_KEY` for Google Gemini) |

   Generate the secrets:

   ```bash
   openssl rand -hex 32
   ```

   Everything else in the file has a working default.

3. ### Configure reverse proxy or domain (optional)

   By default, `docker-compose.yml` publishes the frontend on port `80` (or `FRONTEND_PORT` in `.env`).

   <Tabs>
     <TabItem label="You run Traefik">
       Copy `docker-compose.override.example.yml` to `docker-compose.override.yml`:

       ```bash
       cp docker-compose.override.example.yml docker-compose.override.yml
       ```

       Edit the `frontend` service labels in `docker-compose.override.yml` with your hostname and certificate resolver:

       ```yaml
       - "traefik.http.routers.runway.rule=Host(`race.example.com`)"
       - "traefik.http.routers.runway.tls.certresolver=your-resolver"
       ```

       Docker Compose automatically applies `docker-compose.override.yml`, which is gitignored so your personal setup is never committed or overwritten during updates.
     </TabItem>
     <TabItem label="You run something else">
       Set `FRONTEND_PORT` in `.env` if you want to bind to a non-standard port (e.g. `FRONTEND_PORT=8080`), and terminate TLS in front of it with Caddy, nginx, or your reverse proxy of choice.
     </TabItem>
   </Tabs>

4. ### Bring it up

   ```bash
   docker compose up -d --build
   ```

   Watch for all services healthy:

   ```bash
   docker compose ps
   ```


</Steps>

## Grading photos

The launchers offer the honour system and host grading out of the box, and both
run entirely on your instance.

The AI referee needs `SCALEWAY_API_KEY` (or `GEMINI_API_KEY`) in your `.env`. The server is told a key
exists and the worker is given the key itself, so the card appears in the
launcher only when a backend can answer it. Cheap EXIF and GPS-velocity
heuristics run first and reject some captures at zero API cost; everything past
them goes to the model. Leave the key empty and the AI card stays hidden.

## Updating and backups

```bash
git pull
docker compose up -d --build
```

Two named volumes hold everything worth keeping: `runway_db_data` has the event
log every race is replayed from, and `runway_minio_data` has the photos. Back up
both together, since a photo whose row is gone is unreachable and a row whose
photo is gone renders as a hole in the race report.
